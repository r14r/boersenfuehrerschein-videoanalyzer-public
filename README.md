# boersenfuehrerschein-videoanalyzer-public

Öffentliche technische Dokumentation des Video Analyzer.

Die Site nutzt **GitHub Pages + Jekyll + Dinky Theme**. Die Navigation liegt in einer festen linken Sidebar über die volle Viewport-Höhe.

Die Inhalte beginnen in `index.md`; Navigation und Theme werden über `_config.yml` gesteuert.
