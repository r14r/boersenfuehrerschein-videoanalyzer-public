# Video Analyzer Documentation

Öffentliche technische Dokumentation des Video Analyzer.

Die GitHub-Pages-Site basiert auf dem **Aviator Jekyll Template** von CloudCannon und wurde für die bestehende mehrseitige Video-Analyzer-Dokumentation angepasst.

## Template-Anpassungen

- Aviator-artige feste linke Navigation über die volle Viewport-Höhe
- responsive Mobile-Navigation
- Suchfeld und clientseitige Dokumentationssuche
- eigene Video-Analyzer-Farbgebung und Logo
- bestehende technische Markdown-Dokumentation und SVG-Diagramme bleiben erhalten
- GitHub Pages Deployment bleibt unverändert
